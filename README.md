# 🚀 100 Days of CKA Preparation

Welcome to my **100 Days of CKA Preparation** journey.

I’m preparing for the **Certified Kubernetes Administrator (CKA)** certification and documenting what I learn through hands-on practice, Kubernetes manifests, commands, troubleshooting scenarios, and exam-focused notes.

The goal of this repository is simple:

> **Learn Kubernetes by doing, document the journey, and build strong practical skills for the CKA exam.**

---

## 🎯 Goals

During these 100 days, I’ll focus on:

- Understanding Kubernetes fundamentals
- Building and managing Kubernetes workloads
- Practicing `kubectl` commands
- Writing and working with YAML manifests
- Kubernetes networking
- Storage and persistent volumes
- Scheduling and resource management
- Security and RBAC
- Troubleshooting Kubernetes clusters
- Cluster administration
- CKA-focused hands-on scenarios
- Improving speed and accuracy with practical tasks
